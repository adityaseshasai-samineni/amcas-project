# Simulator DRAM export
Opt-in AMCAS_DRAM_EXPORT path, emitted at dram_t::push once per admitted controller request. CSV sequence preserves deterministic simulator invocation order (not hardware order). core_cycle is global simulated core-cycle count; partition is decoded controller ID; address_hex is simulator address; write boolean; bytes is mem_fetch data_size; access_type numeric enum. No silent32B expansion. Includes simulated reads/writebacks/RMW traffic that reaches controller, not cachehits. Countcrosscheck against sum perpartition n_req/controller totals required. File closes via normalprocess exit. Do not interpret as real GPUphysicalDRAMcommandtrace. Addressmapping/controller timing models differ from externalRamulator/DRAMsim3; injectiontimes are output from closedlooppipeline and externalreplaydoesnotpreservethatfeedback.
