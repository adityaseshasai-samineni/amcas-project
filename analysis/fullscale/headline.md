# Headline tables: global bank XOR hash vs default mapping

Generated by `fullscale_report.py` from the raw replay files under `cluster-data/results/fullscale/`; do not edit by hand. 'default' = Ramulator RoBaRaCoCh with the intra-channel layout given in `context.md`; 'xor' = the global bank XOR hash searched offline on the same stream (`xor_global`). Percentages are changes relative to the default (negative = the hash is faster or lower). THP = 2 MiB pages with random frames, the only placement in which the hash helps. Saturated replays are bandwidth-bound upper bounds. Latency is the mean read latency in memory-clock cycles.
